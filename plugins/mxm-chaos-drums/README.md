# mxm-chaos-drums (plugin)

The CLAP and VST3 of mxm-chaos-drums: sixteen cells on keys 36–51, their touch keys on 52–67.

- **Strike** a cell key and the note adds charge; **hold** it and it keeps feeding the cell from the
  shared Pool; **let go** and the cell spends what it has.
- **Touch keys** feed a cell's own sound back into it and bridge it to its neighbours.
- **Temper** takes the kit from steady (0) to wild. **Reset on play** restarts every cell when the
  transport starts, so a bounce is what was heard.
- Main stereo plus sixteen mono outputs, or stereo only.

The editor leads with the grid: each square is a cell, filling with its charge; click one to hear
it and edit it. The design is [the brief](../../docs/briefs/mxm-chaos-drums.md).
